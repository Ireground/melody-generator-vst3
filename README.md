# Melody Generator (VST3)

A simple MIDI melody generator: pick a key, scale and complexity, press **Generate**,
then **drag the melody straight onto a REAPER track** as a MIDI item.

## Install (Windows)
1. Open the **Actions** tab of this repository and click the latest green run.
2. Under **Artifacts**, download **Melody-Generator-VST3-Windows** and unzip it.
3. Copy the `Melody Generator.vst3` folder into `C:\Program Files\Common Files\VST3`.
4. In REAPER: Options > Preferences > Plug-ins > VST > **Re-scan**.

## Use
- Put it on a track **before your synth**. It plays the melody in sync with the transport.
- **Drag MIDI**: drag this box onto the arrange view to drop the melody as a MIDI item.
- **Save MIDI...**: saves the melody as a .mid file instead.
- **Generate** makes a new melody, **Back** returns to the previous one.
  The *Melody #* number brings back an exact melody.
